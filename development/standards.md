# Code Standards

This section captures the project’s engineering quality expectations.

## General expectations

- prefer clear, readable, maintainable code
- keep code changes focused and reviewable
- avoid hidden side effects and undocumented state
- follow the project’s linting, formatting, and validation rules

## Architecture expectations

- keep service boundaries explicit
- prefer simple interfaces over complex abstraction layers
- document non-obvious decisions

## Review expectations

Capture how code review quality is measured and what is required before merging.
