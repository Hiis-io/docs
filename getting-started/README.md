# Getting Started

This section is the entry point for anyone onboarding to the Brimweb Patronize project.

## Prerequisites

Before working on the project, confirm the following:

- Required runtime and tooling versions
- Access to project repositories and environments
- Local environment variables or secret configuration
- Development credentials for the relevant services

## Local development setup

1. Clone the project repository.
2. Install dependencies for the target application or service.
3. Configure environment variables from the project template.
4. Start the required services for local development.
5. Run the project verification commands to confirm everything is healthy.

## Project workflow

- Work from a feature branch or task branch.
- Keep changes scoped and reviewable.
- Run tests and static validation before opening a pull request.
- Update documentation when behavior or workflow changes.

## Recommended developer habits

- Keep local environment parity close to staging or production.
- Prefer small, well-named, reviewed changes.
- Record operational risks and assumptions in the relevant docs.
