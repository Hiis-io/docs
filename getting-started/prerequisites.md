# Prerequisites

Before working with Brimweb Patronize, confirm that your local environment includes:

- the required runtime version for the relevant service
- project access and repository permissions
- the correct environment variables and secrets
- any external service credentials needed for local development

## Required access

Document the systems and credentials needed to work on the platform, including:

- source control access
- cloud or infrastructure credentials
- local service dependencies
- testing or staging access for the team

## Environment checklist

Use this checklist before starting development:

- dependencies installed
- local services running
- environment file configured
- branch checked out correctly
- relevant tests or build steps verified
